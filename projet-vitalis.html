Vitalis - Application Mobile

Une application mobile bien-être qui génère un plan de santé personnalisé et accompagne l'utilisateur au quotidien sur 6 piliers : activité, mental, sommeil, nutrition, microbiome et cardio.

Fonctionnalités

  • Onboarding interactif : quiz de profil, sélection des piliers et génération d'un plan personnalisé
  • Dashboard bien-être : score global, série (streak), humeur, hydratation et pas via capteurs
  • Activité : séances de sport guidées avec lecteur intégré
  • Mental : méditations, exercices de respiration et lecteur dédié
  • Sommeil, nutrition et microbiome : suivi par pilier
  • Check-in hebdomadaire qui adapte le plan selon vos réponses
  • Notifications locales et gestion du bouton retour natif Android
  • Application mobile native Android (Capacitor)

Stack technique

React 18 TypeScript Vite Tailwind CSS 4 shadcn/ui framer-motion React Router Capacitor

Application mobile native Android construite avec React + Capacitor, données locales avec notifications et capteurs (mouvement).
