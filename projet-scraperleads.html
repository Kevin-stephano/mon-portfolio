ScraperLeads - Enrichissement de leads

Un pipeline complet de scraping Google Maps et d'enrichissement de données qui détecte les entreprises sans site web et les qualifie pour la prospection.

Fonctionnalités

  • Scraping Google Maps automatisé : nom, adresse, téléphone, catégorie, note, avis et photos
  • Détection des entreprises sans site web (cible de prospection)
  • Vérification Facebook : page peu active = opportunité
  • Enrichissement API SIRENE : forme juridique, chiffre d'affaires, statut, dirigeant
  • Enrichissement Societe.com + Pages Jaunes
  • Extraction d'emails depuis le site web de l'entreprise
  • Score de qualification 0-100 pour prioriser les leads
  • Accroche de prospection personnalisée générée par IA
  • Export Excel avec liens WhatsApp pré-formatés
  • Dédoublonnage et regroupement des leads par secteur

Stack technique

Python PyQt6 / QtWebEngine Playwright API SIRENE Societe.com Pages Jaunes Google Maps BeautifulSoup openpyxl Serveur API de pilotage

Pipeline piloté par un serveur API (statut en temps réel), enrichissement en plusieurs étapes et export prêt pour la prospection WhatsApp/email.
