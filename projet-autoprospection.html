Projet B2B

Autoprospection - Plateforme B2B

Identifier des entreprises sans site web via le scraping de Google Maps, puis générer et envoyer des messages de prospection personnalisés à grande échelle.

Fonctionnalités

  • Gestion des contacts et des segments de prospection
  • Import de données en CSV
  • Emails IA personnalisés pour chaque prospect
  • Envoi de masse avec gestion des envois
  • Suivi des réponses (ouvertures, réponses positives)
  • Relances automatiques selon le comportement
  • Dashboard KPI pour piloter les campagnes

Stack technique

React 18 TypeScript Vite shadcn/ui Laravel Supabase / PostgreSQL n8n DeepSeek / Claude Google Maps annuaire-entreprises.data.gouv.fr

Sources de données : API annuaire-entreprises.data.gouv.fr, complétée par du LLM pour les champs manquants. L'orchestration n8n pilote les appels LLM qui génèrent les emails.
