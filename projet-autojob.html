Autojob - Travail Automatisé

Une plateforme SaaS "Travail en ligne 100 % automatisé" qui détecte les meilleures opportunités freelance (Fiverr/ComeUp) et laisse des agents IA autonomes les traiter de bout en bout.

Fonctionnalités

  • Détection IA des jobs : surveillance n8n (IMAP, RSS) + ajout manuel d'un lien Fiverr/ComeUp
  • Explorateur d'opportunités : recherche, vues grille/liste, prix, client, plateforme
  • Agents IA spécialisés : CODE, WRITE, SEO, CRO Copy, Trad Pro, Combo — routage automatique
  • Dashboard KPI : revenu estimé, tâches complétées, agents actifs, temps économisé
  • Console d'exécution en direct : logs temps réel (Socket.io), start/stop, simulateur de job
  • Pipeline en 4 étapes : Détection → Analyse & Brief (Ollama Llama 3) → Exécution → Livraison
  • Livrables IA vérifiés QA : rendu markdown, aperçu HTML, code téléchargeable
  • Exports : PDF, TXT, Pack Agence ZIP (PDF + CSV + code + guide), Excel élite
  • Post-processeur déterministe : nettoyage IA, annexe technique, détection de doublons, note qualité
  • Système Local-First : Docker + Ollama, zéro coût d'API

Stack technique

React 18 Vite Tailwind framer-motion Express SQLite Socket.io n8n Ollama Groq (Llama 3.1) Docker

Pipeline Local-First : données et traitements sur votre machine, orchestration n8n + LLM local (Ollama) et Groq. Livraison automatique et boucle de paiement internationale (Fiverr/ComeUp, Payoneer).
